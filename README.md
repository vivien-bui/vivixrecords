# vivixrecords

A personal digital zine/archive. `index.html` is the site (archive grid + issue spreads); see `docs/Design_Spec__vol_01_zine.md` for the design system and page map.

## Structure
- `index.html` — the site: archive grid, vol 01 ("one more time"), vol 01a ("a friend moving"), vol 02 ("we were girls together")
- `uploads/` — all photos referenced by the site
- `docs/` — design spec / reference docs
- `support.js`, `image-slot.js` — runtime support scripts
- `404.html` — GitHub Pages deep-link redirect shim
